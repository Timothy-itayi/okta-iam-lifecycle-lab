# Leave hub — 8. HR queue

Date: 2026-10-08, 05:23–05:31 Sydney. Helen can see what is waiting, approve it, or decline it. An approval writes a balance change. It does not edit the HR file.

## Queue

`GET /hr/leave` lists every request. Waiting is `with_hr`. Approved and declined are the later states. A department select filters the same list. Oldest first.

The header count leaves out Helen's own request. The waiting list still shows it, because nobody else can decide it.

A row opens `GET /hr/leave/:ref`. The page shows the same chain as the staff card, the manager's decision, Jev, and the policy check. Approve is the `approve` move, from `with_hr` to `approved`. Decline needs a note. The confirmation is the same window as the other hubs.

## Balance

Approve inserts one row in `balance_changes`: the request reference, the person's email, the leave type, and the working days. `exported` stays 0. `GET /hr/export` lists those rows. `GET /hr/export.json` downloads them. A second download returns the same rows. Nothing in this step writes `hr/employees.json`.
